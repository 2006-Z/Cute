# Cute 🌸

> A cute aesthetic zsh setup for lonely terminals.


---

## ✨ Features

- Pink aesthetic prompt
- Command success/failure status indicator
- Autosuggestions
- Syntax highlighting
- Better `ls` with eza
- Better `cat` with bat
- Custom help command
- Auto removes failed commands from history


---

## 📦 Installation

Clone repository:

```bash
git clone https://github.com/2006-Z/Cute.git
```

Open folder:

```bash
cd Cute
```

Make installer executable:

```bash
chmod +x install.sh
```

Run installer:

```bash
./install.sh
```
